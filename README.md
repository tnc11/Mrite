# 数学建模竞赛 Skill + 论文模板 + 算法库

> 长期维护的数学建模竞赛一站式仓库，集成自动求解 Skill、论文模板、App 版本与常用算法。

---

## 仓库结构

```
.
├── Skill/          # Claude Code Skill：每个 Skill 一个独立子文件夹
│   ├── 数学建模竞赛/   # 数学建模竞赛自动求解 Skill
│   └── README.md
├── 模板/           # 论文 LaTeX 模板：每个模板一个独立子文件夹

│   └── README.md

```

## 各模块说明

### Skill/
基于 Claude Code 的数学建模竞赛自动求解技能集合。每个 Skill 放入独立子文件夹，便于管理多个不同技能。

- **数学建模竞赛/**：放入赛题和数据后，说"开始求解"即可全自动完成：读取输入 → 制定计划 → 逐题求解 → 撰写论文 → 编译 PDF。

### 模板/
论文 LaTeX 模板集合。每个模板放入独立子文件夹，便于维护多个不同风格的模板。

- **数学建模国赛/**：论文 LaTeX 模板的源头，包含 `format.cls` 样式文件、思源宋体字体、14 个章节空白 tex 模板。

### App/
独立的 App 版本集合（待开发），将 Skill 能力封装为可视化应用。

### 算法/
常用数学建模算法代码库，按问题类型分类：优化、预测、分类、评价。

## 使用方式

### 使用 Skill 自动求解
1. 进入 `Skill/数学建模竞赛/` 目录
2. 将赛题放入 `题目/`
3. 将数据放入 `数据/`
4. 在 Claude Code 中说"开始求解"

### 单独使用论文模板
1. 复制 `模板/数学建模国赛/` 下所有文件到工作目录
2. 编辑各 tex 文件填写内容
3. `xelatex 论文.tex` 编译

## 维护约定

- **论文模板**：`模板/数学建模国赛/` 为源头，修改后同步至 `Skill/数学建模竞赛/论文/`
- **编译产物**：`.aux` `.log` `.pdf` 等已通过 `.gitignore` 忽略
- **命名规范**：代码、图、CSV、tex 文件一律中文命名
